# Capcli Handbook

This is the public operating manual for Capcli. 

Everything about how we build software, make decisions, compensate people, and sell to enterprises is documented openly in this repository. 

There are no secret internal wikis, no locked HR Notion pages, and no backdoor policies. If an operational rule is not committed to this repo, **it does not exist.**

---

## The Core Axiom

> **Prompt engineering is dead. We govern agents with physics, not psychology.**

We build the deterministic runtime substrate for the autonomous software era. We replace polite English suggestions with compiled Rust, native C SQLite authorizers, Linux namespace sandboxes, and immutable cryptographic audit ledgers.

We run this company with the exact same rigor: **asynchronous, written, transparent, and PR-driven.**

Our company policies are maintained like code:

1. **Fork this repository.**
2. **Edit the Markdown/MDX file.**
3. **Open a Pull Request with a clear rationale.**
4. If the PR is reviewed and merged into `main`, **it becomes company law.**

Zero committees. Zero executive backdoor overrides.
