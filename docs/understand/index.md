# Understand

You've used Capcli. You've shipped an order, gotten denied, maybe slept well because of a trust receipt.

Now you're asking the dangerous question: *why* does it work?

This section is the mental model behind the experience. No new commands. No homework. Just the physics, explained in the order you'd naturally bump into them.

## The promise of this section

Every page answers one question you already asked while *using* Capcli. We never explain a mechanism before you've felt it push back.

If a page ever feels like a lecture you didn't sign up for, close it. That's not a bug in you. That's a bug in us.
