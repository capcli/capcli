# Guides

Something specific went wrong, or you're doing something specific and unusual. You don't need a journey — you need a fix.

Guides are problem-shaped, not architecture-shaped. In, out, back to work.

---

## How these guides work

Every guide follows the same shape:

```
problem → diagnosis → evidence → remediation
```

Diagnosis starts with a command. Evidence comes from the ledger, not from memory or vibes. Remediation is a command, with intent. If a guide can't follow that shape, it doesn't ship.
