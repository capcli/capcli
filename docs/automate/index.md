# Automate

The automation section has a dirty secret: **none of it starts with automation.**

It starts with you noticing you've typed the same thing three times. Then it escalates — carefully, with evidence at every step — toward work that runs while you sleep.

---

## The ladder

```
you notice repetition
    ↓
routine          — the work becomes a versioned, governed capability
    ↓
rehearsal        — you watch it succeed in sim before trusting it
    ↓
proof            — the evidence that it works, on file
    ↓
promotion        — trust climbs: draft → reviewed → pinned
    ↓
operation        — bindings run it; you watch receipts, not terminals
```

Each rung is a *decision gate*, not a tutorial step. Skip one and the next one refuses to cooperate. That's by design — see [trust.md](../understand/trust.md).

## The philosophy in one line

> Automation without evidence is just a faster way to make the same mistake.

Prompts get vibes. Routines get p95s.
