# Automate

You've typed the same bounded query three times this week. Same `WHERE`. Same Stripe call. Same tidy little update at the end.

Somewhere around the third repetition, a thought arrives:

> **"I keep doing this."**

That thought is the door. Everything in this section exists to answer the question that follows it:

> **"Can this become a routine?"**

---

## The arc

Automation in Capcli isn't a feature you configure. It's a promotion your repetition earns:

```
spot it → name it → rehearse it → prove it → promote it → operate it → subtract it
```

The kernel has been quietly recording every query, every API call, every denial. When a pattern shows up, the audit trail already knows. Your job is to notice it, codify it, and hold the result to the same evidence bar as everything else.

## The One Rule

**Automate what you've repeated. Nothing else.**

A routine born from real repetition arrives with history, real test parameters, and a description that writes itself. A routine born from imagination arrives with none of that — and the kernel will demand all of it.
