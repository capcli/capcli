  - Monorepo layout
    - Tooling
      - Bun IS the monorepo: no turborepo, nx, pnpm, lerna — `bunfig.toml` plus workspace globs
      - Bun resolves, links, runs, tests — one tool, zero orchestration overhead
      - bunfig.toml: [install] peer=false, [test] coverage text+lcov, [workspace] packages=packages/*
      - Root package.json: private, workspaces packages/*, scripts only (dev kernel watcher, build/test/lint via --filter *, test:unit/integration/e2e by tier folder, native:build napi release)
    - Layout: packages/ = types, kernel, sdk, pwa, native; workspace/ git-tracked (world.sql, audit/, schema.yaml, system-schema.yaml, policy.yaml, governance.yaml) + gitignored (workspace.db live) + apis/, routines/ (FIX #31 not wholesale ignored); repo holds architecture+code+config templates, never live data; root law docs architecture.md + seven *.architecture.md siblings
    - Sealing law: domain seals the package, feature seals the file — no file crosses domains, no package leaks
    - Anti-decisions: no Turborepo/Nx/Lerna/pnpm (Bun suffices), no index.ts barrels (*.*.* naming), no NestJS DI (direct imports, handler->service->gate), no dto/ (types in @capcli/types + noun.types.ts), no co-located tests (__tests__/ tiers), no Vitest/Jest (bun:test), no Next/Remix (Vite, no SSR), no CSS-in-JS (Tailwind), no Storybook (ten layers are the story), no monorepo tsconfig (per-package + base), stack.md dead (content lives here)
    - Invariants: package line never cycles (all imports -> @capcli/types); tests mirror source (handler unit, domain integration, lifecycle e2e); deterministic outputs (no timestamps/paths); zero orchestration (if Bun can't, task is wrong); doc bundling at artifacts/repomix.config.json (markdown, token tree)
  - Naming law
    - `*.*.*` — every src file is domain.feature.ext: three dot-separated segments
    - Test files exempt: `domain.feature.tier.test.ts` (four segments) — tier folder decides tier
      # FIX #2: naming law contradicted test naming convention
    - Patterns: handlers/services — noun.verb.ts handler, noun.service.ts logic, noun.gate.ts enforcement, noun.config.ts loader, noun.types.ts re-exports (e.g. db.query.ts); tests — db.query.ts -> db.query.unit/integration/e2e.test.ts, tier folder decides, no orphans; PWA-only suffixes noun.store.ts (Zustand)/noun.view.tsx/noun.hook.ts never outside pwa/src
    - Forbidden
      - Forbidden: index.ts, utils.ts, helpers.ts, constants.ts, bare types.ts, App.tsx
      - A forbidden name hides what the file does — the name is the map
      - Entry points are the sole exception: main.ts at package root, app.tsx in the PWA
  - Packages
    - @capcli/types
      - Single source of shared contracts — zero runtime code, types and const enums only
      - Imports nothing; every other package imports from it; breaking change = major bump
      - Contracts
        - exit.codes, kernel.contract, audit.event, capability, policy, governance, schema
        - budget.types (frame, cascade, session pool), identity, env, api, routine, bind, ping
        - sdk.contract (createKernel return type) and cli.types (args, flags, output shapes)
      - src/main.ts is the barrel export — the sole entry-point exception here
    - @capcli/kernel
      - The gate: handler (noun.verb.ts) → service → gate; direct imports, no decorators, no DI
      - boot.ts: quad-lock compile, refuse-or-serve; config/citty.commands.ts defines the CLI tree
      - Domains: db (query/exec/lock/unlock/snapshot/restore/dump/schema; gates authorizer+AST+prepare cross-check), routine (draft/prove/ship/sweep/stats/rollback/retire; manifest AST-extract, fingerprint diff, sandbox jail orchestrator: see action.md#Routines), api (sync/diff/catalog/activate/prove/ship/stats/retire/deactivate/rollback/list; quota/enforce, egress+secrets, sim fixtures), bind (cron/webhook/endpoint/list/inspect/pause/resume/remove/keys; Bun.serve daemon), ping (notify/ask/list/resolve/expire — smallest domain), rule (schema/system/policy/governance loaders; show/diff/apply/validate), env (new/use/list/inspect/doctor/merge/remove; git worktrees: see space.md#Environment-axis), sys (audit tail/trace/query/replay, agent register/list/revoke, doctor/backup/recover/exec/serve; audit JSONL+mirror+hash, budget frames+cascade), run (exec/search/inspect cost envelope; registry resolver), identity (principal/agent/session, SO_PEERCRED socket, skill_origin)
      - shared/
        - intent.validator (min words, blacklist), trust.ladder, config.validator (valibot)
        - output.formatter (pretty vs --json), git.service (commit, push, worktree, recover)
      - config/
        - citty.commands.ts — CLI tree definition
        - kernel.config.ts — workspace path, env detection
    - @capcli/sdk: thin wrapper, no logic — createKernel() in main.ts via sdk.kernel.ts; surface sdk.run/db/routine/search/inspect/audit, sdk.brand.ts white-label, sdk.stream.ts WS/SSE for tail follow; sdk.architecture.md embedder-facing: see interface.md#SDK-contract
    - @capcli/pwa: stack law: see interface.md#PWA-layers; TanStack polls kernel, Router navigates ten layers; src/layers/ ten folders (world, capability, governance, audit, budget, environment + approval, recovery, learning, identity; shell+views+hooks+types sealed per layer); stores kernel/audit/approval/budget/env/navigation; components ui.dag/diff/denial/masked/quadlock/confirm + table/card/gauge/badge/breadcrumb; hooks kernel.call/audit.poll/quota.poll-30s/approval.poll-2m
    - @capcli/native: Rust crate capcli_db (napi 2, napi-derive 2, rusqlite 0.31 bundled, cdylib; Cargo.toml/build.rs/lib.rs entry + db.*.rs modules); one module per function — open/authorizer/query/execute/snapshot (VACUUM INTO)/restore + types bridges; exactly six fns; authorizer closure from compiled policy; napi build --release -> capcli_db.node; tests from TS through napi (authorizer unit + deny-path integration)
  - Test architecture
    - Three tiers: unit (<50ms, pure mocks, one function one decision — AST rejects WHERE-less UPDATE, intent junk, ladder resolve; bun test __tests__/unit/), integration (<5s, real SQLite temp fs no network — authorizer denies ATTACH, db exec, prove, sync, apply, quad-lock, merge), e2e (<60s, real workspace+git+sandbox — intent->world->deny->write->recover); runner bun:test everywhere, Playwright PWA-e2e only
    - e2e suites: kernel (onboarding.journey, routine/api lifecycle, multi.env, budget.cascade, recovery.worst.case wipe->clone->recover; temp workspaces per test via createTempWorkspace, no shared fixtures; real kernel process, Playwright real browser never mocked) + PWA (onboarding.render 11 stages, approval.flow, audit.drill, recovery.confirm; config in packages/pwa)
  - Build & run
    - Commands: native once/Rust-change (napi build --release); dev kernel watcher / PWA; build+test all via root filtered scripts; one tier bun run test:unit|integration|e2e; SDK publish bun build src/main.ts --outdir dist --target node
    - Outputs: kernel->dist/cli.js (Bun single-file), sdk->dist/index.js+.d.ts (ESM+types), pwa->dist/ (Vite static), native->capcli_db.node; deterministic (no timestamps/paths, diffable — changed binary means changed inputs)
    - Stack: Bun runtime; SQLite via rusqlite/napi-rs; L1 authorizer closure C-level + L1.5 prepare cross-check (prepare_v2+EXPLAIN); L2 AST node-sql-parser sqlite dialect; CLI citty; YAML yaml; validation valibot; PWA React 19/Vite 6/Tailwind 4/Zustand 5/TanStack Query 5/Router 7/Playwright; Bun built-ins zero-dep (serve/spawn/file.writer/CryptoHasher-sha256/randomUUID/bun:test/env/bunfig); kernel npm deps 4 (node-sql-parser, yaml, valibot, citty) + rust 3 = 7; PWA-only react/zustand/tanstack/router/tailwind (FIX #24 not kernel)
  - Dependency graph: types <- kernel <- sdk <- pwa (acyclic unidirectional; types imports none; kernel +native; sdk +kernel; pwa +sdk runtime only; no cycles, no kernel->PWA, PWA->kernel only via SDK); ownership — kernel domains: kernel devs (agent read-only ref); pwa: frontend; native: Rust; schema.yaml + routines/*.py: agent governed via gate; system-schema.yaml: kernel releases only (agent read-only); apis/*.yaml: kernel-compiled; policy.yaml+governance.yaml: human-owned (agent read-only); src/** out of agent reach — gate is only write surface
