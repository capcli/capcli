  - CLI surface
    - Design laws
      - Shape: `capcli <noun> <verb> [target] [--flags]`; search/inspect are verbs under run (`capcli run search/inspect`; top-level aliases accepted, FIX #22)
      - Nine nouns: run, db, routine, api, bind, ping, rule, env, sys; built on citty; each subcommand declares typed args
      - Registry: everything resolves through it (db ops, routines, api verbs, views); one registry serves CLI, SDK, PWA
      - Output: humans tables, agents/PWA --json (versioned machine contract); [env] prefix: see space.md#env-command
      - Exit codes: see physics.md#Fail-closed-stance (0 ok / 2 denied / 3 validation incl. boot/drift/migration FIX #11/#12 / 4 runtime / 5 audit-write-failed); branch on codes, never stdout
      - Intent: --intent required on all writes; junk intent = exit 3; leaf ops inherit routine/session chains
    - `run` noun — hot path
      - Verbs and flags
        - `run <capability> [-p k=v]` — the primary skill-to-routine bridge
        - `run` accepts `--dry-run`, `--intent`, `--lock <ref>`, `--json`, `--as`, `--by`
        - `search <query> [--trust X] [--env X] [--max-ops N]` — deterministic filters
        - `run search <query> [--trust X] [--env X] [--max-ops N]` — canonical form under run noun
        - `run search gaps --since 7d` — searched-never-invoked gap report
        - `run inspect <capability>` — the full cost envelope in one JSON blob
          # FIX #14/#22: search gaps and inspect now under run noun
        - Search resolution ladder: see physics.md#Search-ceiling
      - inspect envelope (one JSON blob, go/no-go): tokens (file_size, max_result_tokens, params_schema_bytes); duration (max_seconds 300, p50/p95 from audit mirror); db (writes/reads per run, max_rows); concurrency (max_ops 50, active_claims); frequency (calls_last_hour vs limit); success (total_runs, success_rate, manifest_match_rate); api (calls_per_run, providers, live_quota, daily_budget vs remaining, sim_mode per verb: see space.md#Rehearsal-&-sim; prove_status total vs provable, skipped-verb records, gov.file_tax_return prod-only first-3-gated); composition (depth, children, budget_inheritance min); budget_status: see budget.md#Exhaustion + #Quotas
      - inspect behavior
        - `inspect` is a read: exit 0 always — denial happens at `run`, not here
        - Discovery without cost awareness invites denial — inspect first, run second
        - The envelope powers go/no-go in agents, harnesses, and the PWA
    - `db` noun — world state
      - `db query <sql> [-p k=v] [--limit N] [--count]` — the read path, always first
      - `db exec <sql> -p k=v --intent "..."` — auto-txn, WHERE+LIMIT enforced
      - `db lock <table>:<ref> --ttl 10m --reason "..."` — TTL lease for cross-agent claims
      - `db unlock <target>` — release the claim
      - `db schema [--table]` — DDL, CHECK constraints, provenance
      - `db snapshot | restore <id> | dump` — mechanics: see recovery.md#Snapshots
      - `db count` is dead — `db query --count` or AST-enforced pre-flight
    - `routine` noun — learned procedures
      - `routine draft <name> [--reason]` — create + validate + manifest extract
      - `routine prove <name> [-p k=v] [--env sim]` — fingerprint vs manifest: see action.md#Manifests-&-fingerprints
      - `routine ship <name> --to reviewed|pinned [--env X] --reason "..."` — human-gated
      - `routine sweep [--since 30d]` — consolidation report: see time.md#Consolidation
      - `routine stats <name> [--deep]` — per-leaf attribution: see time.md#Stage-details
      - `routine rollback <name> --to-version N` — instant, audited
      - `routine retire <name> [--reason]` — uncallable; history and provenance kept
      - Lifecycle stage depth: see time.md#Stage-details
    - `api` noun — external lifecycle
      - `api sync <provider> --from <url> [--interval 7d] [--dry-run]` — scheduled, full catalog
      - `api diff <provider>` — spec drift since the last sync
      - `api catalog <provider> [--state dormant|active|deprecated|retired]`
      - `api activate <provider.verb> --intent "..."` — dormant → active at trust draft
      - `api prove <provider.verb> [-p k=v] [--env sim]` — adapts to sim_mode: see space.md#Rehearsal-&-sim
      - `api ship <provider.verb> --to reviewed|pinned --reason "..."` — same ladder as routines
      - `api stats <provider> [--deep] [--summary]` — per-verb or rollup
      - `api retire | deactivate <provider.verb> [--reason]` — deactivate returns to dormant
      - `api rollback <provider.verb> --to-version N`; `api list [--provider X] [--state X]`
    - `bind` noun — inbound triggers
      - Verbs
        - `bind cron <name> --run <cap> --cron "..." --intent "..."` — time trigger
        - `bind webhook <name> --provider X --event Y --run <cap> --intent "..."` — async event
        - `bind endpoint <routine@version> --auth api-key [--rate X]` — sync endpoint
        - `bind list | inspect | pause | resume | remove <name>` — management
        - `bind keys issue <name> --principal partner:X` — human-gated
        - Endpoint bindings pin the exact routine@version
        - Trigger domain depth: see action.md#Bindings
      - Serve split: `bind endpoint` registers config to workspace.db (exit 0, no listener); `sys serve --start/stop/restart/status` launches the daemon (Bun.serve or companion; prod under systemd/supervisord); daemon enforces same policy gates as run; health: endpoint --health 200/503, sys doctor checks all
      - Request audit: every HTTP request emits serve.request (endpoint, routine, api_key_id, principal, status, duration) — closes CLI/HTTP audit gap
    - `ping` noun — outbound human IO: notify <principal> <msg> --channel --intent (one-way); ask <principal> <q> --options --timeout --intent (blocks fail-closed on crash: see physics.md#Fail-closed-stance); list [--pending]; resolve <ask-id> --choice (kernel resumes); expire <ask-id>; asks audited like any op
    - `rule` noun — static config: show [--type schema|system-schema|policy|governance] (one noun, four layers); diff [--git]; apply [--type schema] [--dry-run] (world tables only, agent-triggered; system-schema boot/kernel-upgrade only); validate (all layers + quad-lock: see physics.md#Fail-closed-stance)
    - `env` noun — switchable worlds
      - `env new <name> --seed prod [--from-branch X]`: see space.md#env-command
      - `env use <name>` — atomic switch
      - `env list | inspect | doctor` — worlds, drift, unmerged routines
      - `env merge <name> --into prod` — promotion travels by git merge
      - `env remove <name>` — prod removal multi-flag gated
      - Axis and worktree depth: see space.md#env-command
    - `sys` noun — kernel and audit
      - `sys audit tail [--follow] [--capability X] [--since 1h]` — live and filtered stream
      - `sys audit trace <op-id> [--explain]` — causal DAG + denial reason: see effect.md#Audit-spine
      - `sys audit query <sql> [-p k=v]` — SQL against the _audit mirror
      - `sys audit replay --from <ts|event-id> [--dry-run]` — re-run from a point
      - `sys agent register | list | revoke`: see agent.md#Identity-hierarchy
      - `sys doctor` — boundaries, perms, drift; refuses to serve on broken boundaries
      - `sys backup [--push] | recover <commit>`: see recovery.md#Restore-path
      - `sys exec <cmd> --sandbox` — jailed execution, the only jail surface
      - `sys serve --start | --stop | --restart | --status` — the HTTP daemon
    - Daily surface: loop = search -> inspect -> run -> trace, reads first (db query), --dry-run before first effect; discovery extras (catalog --state dormant, search gaps, api stats --deep, rule show --type policy); db exec direct instruction is [human], skills never instruct it; caller tags [harness]/[human]/[both]
    - Refusals: config write-paths (config set; rule apply --type system-schema; schema edit — files+git+review only); dead/replaced (db count -> db query --count; claim -> db lock/run --lock; jail -> sys exec --sandbox; policy explain/--verbose -> audit trace --explain/tail; api call -> run/ctx.api.call; budget noun -> inspect envelope); override flags (--force/--override-budget/--force-prod refused: see physics.md#Two-layer-enforcement, governance overrides only); API limits (api import --pick: see action.md#External-APIs; api create/simulate refused — sync/sim_mode only); UX/meta (no interactive modes/wizards — harness+PWA render; one event per verb; no separate config/trigger nouns)
  - Universal flags
    - Every verb: --json (versioned machine contract; agents+PWA always), --as <principal> (scoped views require it), --env <name> (explicit cross-world targeting: see space.md#Environment-axis)
    - Mutating: --dry-run (full pipeline zero effects, mandatory before first effect), --intent (required on writes, anti-junk, chains inherited), --reason (threshold crossings: see trust.md#The-ladder), --by <agent-id> (socket-verified acting identity: see agent.md#Identity-hierarchy; --by acts, --as is for whom)
    - Scoped: --lock <ref> (run only, TTL lease), --sandbox (sys exec only, bwrap/podman net-none ro binds; only jail surface; FIX #23 noun-scoped flags frozen)
  - SDK contract
    - Entry: import { createKernel } from @capcli/sdk; createKernel({ workspace, brand }) or from JSON config; PWA and embedders share it; same { exit, json, text } + exit codes; sdk.architecture.md embedder-facing hidden
    - Brand: name + cli required, tagline optional, nouns surface-only aliases (run->exec, db->store, routine->flow), lockedNouns default [sys]; text-only — JSON/exit/audit never rebranded
    - API: kernel.run(cap, {params,intent,json,dryRun,env}), db.query/exec, routine.prove, search/inspect; audit.tail (snapshot or follow:true WS/SSE), audit.trace(opId); all return { exit, json, text }
    - Never changes: exit codes, JSON contract, [env] prefix, audit format, system tables, config names, ctx contract: see action.md#The-ctx-contract
    - White-label hidden from workspace docs/--help/doctor/governance; discovered via TS intellisense; PWA is primary consumer
  - PWA layers
    - Convictions: renderer of governed queries never creator (agent defines, kernel gates, PWA renders); every pixel a kernel artifact; causal DAG is navigation; exactly five interactions (browse/approve/answer/recover/observe); trust calibrator; thinnest layer
    - NOT: not a kernel component (client outside workspace), not CLI replacement (calls SDK), not second kernel (never gates/enforces/audits), not agent harness (humans only), not interactive terminal (exit codes + approval cards)
    - Ten layers
      - Layer 1 World: tables as browsable trees (columns/CHECK/relations/seed); browse = kernel.db.query as table; row click -> touching audit events; mask=true locked cells; system tables read-only badge; column header -> governing policy; depth: see world.md#SQLite-as-SSOT
      - Layer 2 Capability: routines browser (trust badge, env journey dev/sim/prod, version diffs, manifest vs fingerprint match_rate + drift + side-by-side, gaps visible, promote/rollback/retire -> L7/L8); api verbs by state (active/dormant/deprecated, prod-only gap + first-calls); binds panel (cron/webhook/endpoint health+keys); search analytics (top queries, gaps, denial patterns); depth: see action.md#Capability-registry
      - Layer 3 Governance: policy.yaml interactive tree (rule -> denials citing it); governance.yaml limits + live usage bars; schema.yaml ERD + diff vs live; system-schema read-only; quad-lock banner (mismatch red); depth: see physics.md#Two-layer-enforcement
      - Layer 4 Audit: live tail kernel.audit.tail({follow:true}); event cards (intent_chain, rules_matched, rows, result_hash); caused_by breadcrumb; denial forensics trace --explain; fingerprint views; primitive cost/subsequences feed L9; depth: see effect.md#Audit-spine
      - Layer 5 Budget: frame tree per session (declared/inherited/consumed, active/EXHAUSTED); session spend pool + provider breakdown + time-series; rate gauges; exhaustion denial card + session remainder; depth: see budget.md#Frames
      - Layer 6 Environment: dev/sim/prod cards (prod red); sim (seed source, masking, stale nag, overlays); dev (drift, unmerged, looser overlay); new env -> env new --seed prod; depth: see space.md#Environment-axis
      - Layer 7 Approval: promotion queue (evidence, manifest diff, SLA countdown); activations (slots, first-prod-call windows); migrations (DDL preview, snapshot, rollback preview); merges (similarity, fork option); asks (ping.ask cards + timeout, resolve resumes kernel); history (approved/rejected/vetoed); depth: see trust.md#Gates-&-promotion
      - Layer 8 Recovery: snapshots (restore/inspect), version rollback chains, git points (sys recover --list), object storage (last push, hash, chain status), worst-case clone+recover (simulated dry-run first); depth: see recovery.md#Restore-path
      - Layer 9 Learning: search gaps (searched N invoked 0 -> propose), consolidation signals (similarity, subsequences, next sweep), decay candidates, denial patterns, trust receipt card (sys doctor --report); depth: see time.md#Learning-loop
      - Layer 10 Identity: principal cards (agents, sessions, approvals, revoke), agent cards (routines, denials, revoke, skill_origin); depth: see agent.md#Identity-hierarchy
    - Navigation: one connected graph as nested trees; drill row -> event -> routine -> manifest -> verb -> quota -> frame -> session -> agent -> principal; link keys caused_by/routine/frame_id/session/agent/principal/rules_matched/snapshot/code_hash; every click a --json call, every render a kernel artifact
    - Rendering: array->table, object->card, ts->chart, remaining/limit->gauge, caused_by->breadcrumb, manifest/fingerprint->side-by-side; exit codes drive UI (0 green, 2 red+rule+fix, 3 yellow, 4 orange+trace, 5 black nothing-ran; can_invoke_now false -> orange banner); trust/env/sim_mode/mask badges; never interprets stdout
    - Real-time: audit tail + budget frames WS/SSE; near-real-time polls (quota 30s, asks 30s); periodic (stats 5m, gaps 1h, drift 15m, backup 15m, approvals 2m); hash chain daily; never caches past TTL
    - Mini ERP: cards (orders today, revenue 7d, low stock, routine health, budget session vs frame) — every card a governed view/audit query, filters are query params, time-series from mirror GROUP BYs, alerts are routines (bind cron -> check -> ping notify) shown never created; business layer over governed world
    - Stack: React 19 + Vite 6 + Tailwind 4 + Zustand 5 (no Next/SSR); kernel JSON single source; TanStack Query polling + WS/SSE; PWA manifest + service worker (installable, offline last-known); auth session token -> --as: see agent.md#Sessions-and-sockets; charts deterministic from audit; no LLM, zero inference
    - White-label: brand nouns render (Routines->Flows etc.); config via createKernel(), lockedNouns unaliased; sdk.brand.ts + brand.resolver.ts; never changes: exit/JSON/audit/tables/[env]/approvals
    - Anti-decisions: no SQL editor/chart builder/alert builder/routine-schema-policy editors/dashboard builder (governed views + routines + harness authorship only); no direct SQLite (kernel.db only); no --force buttons (governance overrides); no bulk approval without evidence; no silent recovery (audit event rendered); PWA never writes _audit; no Metabase/trigger.dev/Grafana/pgAdmin/Airtable/Retool
    - Invariants: every interaction a kernel SDK call (no client-side governance math); every approval an audit event; every denial cites rule/layer/fix: see effect.md#Denials; masked always masked; single-principal one human/session/view; quad-lock always visible; recovery needs confirmation
    - Tool analogs: Prisma Studio->L1, Datadog APM->L4 DAG, GitHub PR->L7, AWS IAM->L3+L10, git history->L8 (never Metabase et al — refused above)
  - Interaction patterns (five only): browse (read-only drill table->rows->row->history; filter/sort are query params; row->audit events, column->policy rules); approve (promotion queue->evidence->approve/reject; rejections carry reasons; approvals are audit events; no bulk); answer (ping.ask->choose->kernel resumes via ping resolve; anatomy q/options/timeout/ask-id; expire retires; crash fail-closed); recover (snapshot restore, rollback: see recovery.md#Restore-path; confirmation always; post-op audit rendered); observe (live tail, gauges, frames; 30s polls; never cached past TTL); no others — no create/edit/configure, no [Y/n]/wizards, single-principal
  - Onboarding journeys
    - Convictions: not a tutorial but a competence loop (unknown -> act-safely/see/recover/return); intent first infrastructure second; harness builds, kernel gates, human approves; first denial is a feature (designed, explained, bounded); recovery proof before power; deletion is state transition: see recovery.md#Destruction-as-transition
    - Neuroscience: reward-prediction-error (deny->explain->succeed beats instant success; first denial before first write); cognitive load (~4 chunks: World/Gate/Capability/Audit/Recovery, one at a time); self-determination (autonomy/competence/relatedness); errorless learning (reads->writes, dry-run->real, dev->sim->prod: see trust.md#The-ladder); trust calibration (5 experiences: allowed read, denied write, governed write, recovery, promotion gate); endowment (user co-creates schema); Zeigarnik (every loop closes); episodic memory (return answers where/what-changed/safe-next)
    - Intent-first law: first object is an intent not a table (no empty world, content generated per intent — refunds world differs from inventory); harness drafts schema.yaml + minimal policy overlay, `rule apply --type schema --dry-run --env dev` shows plan (tables/columns/indexes, capabilities to register, snapshot id, reversible, no effects), human approves via PWA card (kernel has no [Y/n]), `rule apply --env dev --intent` applies (snapshot, DDL, audit, auto-commit); audit honesty — no onboarding.* events, first events rule.apply/db.query-0/denied-exec/allowed-exec, every stage evidence queryable; kernel never infers schema from NL and never generates onboarding content (harness authors, kernel gates, human decides)
    - Human journey S0-S10: S0 install+verify (`sys doctor` boundary checklist, actionable failures, 15s safe); S1 intent capture (one question, refunds/inventory/cleanup/webhook examples, no jargon); S2 minimal world proposal (dry-run tables/caps/reversible, harness dialog, snapshot id, no effects); S3 first safe read (count(*) -> 0 exit 0, chunk World); S4 designed denial (unbounded UPDATE exit 2 require_where + trace --explain, scripted, chunk Gate — the most important stage); S5 first governed write (bounded UPDATE exit 0 rows 1 + trace causal spine, chunks Capability+Audit); S6 recovery proof (snapshot->mutate->restore snap_onboarding_002, or backup --push/sys recover: see recovery.md#Restore-path, chunk Recovery); S7 discovery (search->inspect->run --dry-run, 4 commands, registry lesson); S8 routine formation (3x pattern -> draft + prove --env sim, exploration->exploitation); S9 promotion with evidence (stats --deep 12 runs 1.00 matched, ship --to reviewed --reason, human grants: see trust.md#Gates-&-promotion); S10 trust receipt (`sys doctor --report`, every line audit evidence, shareable advocacy)
    - Harness journey H0-H7: H0 machine contract (`sys doctor`/`env list`/`rule show --json` — env, versions, boundaries, health, no world yet); H1 discover don't guess (search+inspect --json, never guess tables/verbs/params/rules); H2 dry-run before effect (`run --dry-run --json`, validates params+intent, errorless learning); H3 first read (`db query --json`, cheap model-building, shapes from db schema); H4 first governed write (`db exec --json` — exit/decision/rows/audit id, never parse stdout, id is H5 handle); H5 learn from denial (trace --explain --json, adjust intent/WHERE/LIMIT/sim/routine, every retry carries a change); H6 routine formation (GROUP BY 3+ occurrences -> propose, kernel gates registration, proposal carries evidence); H7 prove before trust (prove --env sim --json, never self-promotes, evidence then proposal)
    - Shared loop: intent -> minimal world -> safe read -> dry-run -> designed denial -> small write -> recovery drill -> discovery -> routine proposal -> sim prove -> human promotion -> trust receipt (human traverses for understanding, harness for contract); teaches human safety/control/evidence/reversibility, harness contract/boundaries/capability/feedback, both that gate is physics not punishment; 10-min timeline (doctor 0:00, intent 0:15, world 1:30, denial 3:00, write 4:00, recover 5:00, search 6:00, prove 7:00, stats 8:30, receipt 10:00); milestones human-7/harness-9; metrics first-effect <5min, first-denial <7min, first-recovery <10min, 100% can answer what-happened from audit, json-only no-blind-retries sim>0.9; every stage ends visible+auditable, never trust-me
    - PWA rendering: stage outputs as kernel artifacts (doctor checklist, preview card, denial teaching card, restore flow); S7 three-step wizard, S8 manifest-vs-fingerprint side-by-side; PWA never generates content (harness generates from intent, PWA renders); all 11 renderings drillable views
    - Onboarding anti-decisions: no blank dashboard (see space.md#Environment-axis), no static tour (generated from intent), no docs-dump before first effect, no kernel-generated schema (harness authors), no synthetic onboarding.* events, no interactive modes (exit codes + harness UI), no prod in first 10 min (dev writes, sim proving, prod earned), no all-commands-at-once (4 daily, rest contextual), no unclosed loops, no mysterious denials (cite rule/layer/fix), no destructive deletion (retirement + backup-confirmed removal)
