  - Environment axis
    - World definitions
      - dev world
        - purpose — birthplace for exploratory authoring
        - trust — all rungs execute: draft, reviewed, pinned
        - risk — no live risk: see trust.md#Weakest-link-matrix
        - pre-flight — bulk pre-count checks waived
      - sim world
        - purpose — proving ground for production candidate routines
        - data source — seeded from prod with sensitive data masked
        - trust — reviewed and pinned execute; draft executes strictly under `capcli routine prove`
        - execution — real historical audit inputs replayed against candidates
      - prod world
        - purpose — live operational destination
        - exclusivity — pinned trust on Tier 1 hosts only: see trust.md#Weakest-link-matrix
        - violation — draft or reviewed invocation fails closed at pre-flight with exit 2 (E046_TRUST_VIOLATION): see physics.md#Exit-code-law
    - Alignment conventions
      - orthogonality — environment bounds data; trust bounds capabilities
      - default pairs — see trust.md#Weakest-link-matrix
      - travel law — routines travel dev → sim → prod via manifest promotion pipelines
    - Policy overlays
      - mechanism — unified engine parameterized per environment
      - endpoint remap — base_url swapped via apis/<provider>.sim.yaml
      - notification routing — sim notification primitives rerouted to isolated simulation sink
      - capacity limits — max 5 concurrent environments (prod, dev, sim, 2 experiments)
      - sim defaults — mode resolution: see artifacts/governance.yaml#api
    - World governance
      - namespace boundary — capcli/envs/<name>/ is an isolated directory namespace containing declarative overrides and state
      - substrate isolation — capcli/envs/<name>/workspace.db and capcli/envs/<name>/audit.db are uncommitted, locally managed SQLite instances
      - filesystem mandate — POSIX locking compliance required: see physics.md#Platform-tier-taxonomy
      - prod promotion gate — `env merge <name> prod` verifies Tier 1 host first: see trust.md#Weakest-link-matrix
      - prod protection — operations require out-of-band cryptographic challenge signatures (WebAuthn/Passkey or GPG/SSH key) via Cockpit challenge or local key; CLI flag bypasses rejected
      - backup mandate — git and object push required on mutation
  - Primitive scoping
    - Event identity
      - stamping — leaf events stamped with env and stage: see effect.md#Event-anatomy
      - segregation — sim and prod events maintain distinct namespaces
      - denial logging — rejected operations record world context
    - Idempotency boundaries
      - key formulation — key = f(routine_version, params, env): see agent.md#Concurrency-scope
      - isolation — sim replay execution cannot collide with prod keys
      - scope mandate — cross-environment key sharing denied
    - Quota isolation
      - accounting — _api_quota tracks usage partitioned by env: see budget.md#Quotas
      - independence — sim rehearsals consume sim quota only
      - gating — exhaustion denies calls at target world gate
    - Composition propagation
      - cascade — child verb constraints propagate up call stack: see budget.md#Cascade
      - unproven gaps — prod-only children route to schema-validated mocks: see #Sim-mode-taxonomy
  - Rehearsal & sim
    - Rehearsal workflow
      - environment selection — capcli env use sim
      - simulation run — capcli run <capability> -p k=v
      - inspection — capcli sys audit tail --routine <capability>
      - production switch — capcli env use prod
    - Data masking
      - fork rule — sim_seed_masking: enforce (artifacts/governance.yaml)
      - redaction — mask=true columns populated with valid typed synthetic values via Format-Preserving Anonymization (FPA)
      - type validity — emails become anon_*@sim.local; raw unicode blocks (████) banned in data files
    - Sim mode taxonomy
      - sandbox — HTTP routes to provider test endpoint via overlay
      - mock — kernel replays verified HTTP exchange from apis/<provider>.cassette.jsonl; unrecorded endpoints fail closed
      - federated mock — ws:// calls auto-replay recorded responses from federation/cassettes/<target_ws>.<routine>.jsonl when peer socket is absent or running in sim/CI
      - dry-run — parameter and policy check returning simulated: true
      - skip — excluded from execution; omitted from fingerprint
      - prod-only — execution routes to schema-validated mock fixtures in sim; physical egress strictly denied outside prod
    - Historical replay
      - command — capcli sys audit replay --from prod --since 7d
      - database ops — deterministic re-execution against forked state
      - external ops — manual human confirmation required for HTTP re-fire
  - Drift
    - Manifest drift
      - runtime comparison — dynamic fingerprint diffed against manifest
      - anomaly event — divergence triggers governance.anomaly audit event
      - review impact — undeclared primitives block auto-promotion
    - Environment drift
      - detection — env doctor checks unmerged production routines
      - inspection — env inspect flags schema drift and data staleness
      - staleness threshold — sim data older than 14 days triggers re-seed nag
      - deprovisioning — prod removal auth: see #World-governance
  - env command
    - Management commands
      - provisioning — env new <name> [--seed prod]
      - activation — env use <name>
      - audit — env list, env inspect, env doctor
      - merge — env merge <name> [target=prod]
      - deletion — env remove <name>
    - Safety controls
      - prod destructive auth: see #World-governance
      - git push gate — prod merge requires verified remote push credentials via git push --dry-run
      - merge scope — declarative schemas, routines, and revision bundles only; binary database files remain strictly partition-local
      - merge pipeline — env merge verifies Tier 1 host, runs rule prove in sim, snapshots target DB, then executes phased cutover: see world.md#Revision-safety
        - rehearsal verbs — rule prove rehearses the four phases in sim: see interface.md#Governance-path:-rule-noun
        - fail-closed — pinned-routine break aborts rehearsal with exit 2
